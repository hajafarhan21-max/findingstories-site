# Governed project publishing workflow

Azizi Florence remains the protected benchmark and uses its existing production renderer. Other project guides use the same buyer-first sequence—identity, snapshot, story, residences, location, considerations, provenance, related discovery and attributed enquiry—through the universal renderer in `scripts/generate-platform.mjs`.

## Adding or updating a project

1. Research the official developer/project source. Keep unknown values `null`; historical launch terms must not be presented as current.
2. Add the reviewed identity, residence mix, location and official source to `platform/verified-portfolio.js`.
3. Register approved media only when its source URL, source type, review date, project association, verification state and usage approval are recorded. Otherwise use the explicit branded fallback; it must not look like a rendering.
4. Add a project-specific theme in `platform/project-experience.js`. Themes control accent, section balance and editorial mood without making factual marketing claims.
5. Run the generator. `publicReadyProjects()` applies the deterministic publication gate before a record can enter cards, filters, project pages or the sitemap route inventory.
6. Reconfirm current commercial information through the protected enquiry workflow. Project slug, name, developer and area are included in its existing context payload.

## Minimum public-ready evidence

- verified identity, developer and location;
- a meaningful overview and useful residence snapshot;
- an approved, provenance-bearing visual or the intentional Finding Stories fallback;
- an official source and review date;
- an attributed project enquiry; and
- no unsupported price, payment plan, handover, travel-time or availability claim.

Records that fail remain `internal`, `draft` or `research-ready`; only `public-ready` records are promoted. Optional architecture, amenities, gallery, masterplan, map, nearby destinations and floor-plan sections are rendered only after the corresponding governed data exists.
