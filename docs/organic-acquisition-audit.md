# Organic Acquisition Audit — Azizi Florence Reference Launch

## Findings and priority

### P0 — revenue blocking

No P0 defect was found in the reviewed path. The verified project gate, enquiry persistence, duplicate handling and advisor notification path remain outside this change.

### P1 — organic launch required

- The project registry carried only a title and description, so future launches did not inherit intent, discovery-card, image or FAQ inputs.
- Florence metadata covered the brand but weakly expressed high-intent price, payment-plan, floor-plan, availability and EOI needs.
- The homepage linked Florence manually beside generic opportunity cards rather than deriving approved public projects from the registry.
- Buyer answers were not visibly consolidated, and the listing schema did not connect to a visible FAQ entity.
- WhatsApp copy asked only for a general conversation instead of carrying price, availability and payment-plan context.

### P2 — optimisation backlog

- Validate Core Web Vitals using real-user production data before making visual-quality trade-offs.
- Expand location, developer or investment resources only after enough distinct verified material exists and Search Console demand supports a separate page.
- Test CTA wording against qualified-lead rate, not clicks alone.

## Florence intent model

The primary page owns these grouped intents to avoid cannibalisation:

- **Brand/project:** Azizi Florence, project, residences and launch.
- **Transaction:** current price, starting price, availability, unit release, payment plan, floor plans and booking/EOI guidance.
- **Product:** verified townhouse and villa bedroom configurations.
- **Location:** Florence location, map and verified connectivity.
- **Investment decision:** suitability, buyer objectives, terms requiring confirmation and non-guaranteed outcomes.
- **High-intent long tail:** “Azizi Florence current price and availability”, “Azizi Florence payment plan and floor plans”, “how to register Azizi Florence EOI”, and residence-type availability queries.

No supporting URL is recommended yet: the verified material can be answered more authoritatively on the primary page, while separate pages would currently risk thin content and cannibalisation.

## Measurement interpretation

Existing first/latest-touch attribution and project context distinguish campaign, referral and direct visits, while project views, CTA clicks, WhatsApp actions, form starts and successful conversion-type events describe the funnel. Organic classification should be evaluated from Search Console and referrer data without introducing another tracker. A successful lead remains the revenue-facing conversion; analytics failure must never block it.
