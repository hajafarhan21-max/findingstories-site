## Supporting-page decision

No Florence supporting pages are approved in this release. Price, payment plan, location, floor-plan, EOI and investment questions are more useful in the context of the residence collection and enquiry path on the hub. Separate URLs would repeat the same verified evidence and create thin or duplicate pages.

## Evidence gaps intentionally left unpublished

- No approved public floor-plan asset is recorded, so layouts are available only through the request path.
- Live inventory, release-specific incentives and official EOI terms require current confirmation.
- Handover is conditional on a valid verified project value at render time.
- No verified ROI, rental yield, appreciation forecast or guaranteed return is available or claimed.
- No invented travel-time claims or broker-derived project facts were added.
