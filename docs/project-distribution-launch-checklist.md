# Project distribution launch checklist

Use for every approved launch; it is designed for the next 2–3 projects without copying Florence code or facts.

## Approval and sources
- [ ] Approval owner, evidence files and fact-review date recorded.
- [ ] Manifest identity/SEO/distribution fields completed; changing facts reference verified runtime records rather than duplicated copy.
- [ ] Developer/location/property types and any price, plan or completion statement verified.
- [ ] Availability disclaimer present; external links and relationships individually approved.
- [ ] No guarantee, ROI, urgency, scarcity, official-representation or placeholder claim.

## Generate and inspect
- [ ] Run `npm run seo:generate` and `npm run distribution:generate`.
- [ ] Inspect generated registry, distribution JSON, canonical, sitemap, robots and homepage project card.
- [ ] Confirm share title/description/image, Twitter card, alt text and image dimensions.
- [ ] Check 50/100/200 summaries, fact blocks, all 12 copy formats and direct UTM URLs.
- [ ] Human editorial/factual approval recorded; generated copy is never auto-published.

## Discovery and conversion QA
- [ ] Homepage provides a descriptive crawlable link; no thin developer/location page created.
- [ ] Canonical host is `https://www.finding-stories.com`; no preview URL or internal ID leaks.
- [ ] Project view, WhatsApp, form-start, submit/success equivalents remain observable.
- [ ] Submit a controlled test lead and confirm attribution only when explicitly authorized; never disturb production persistence.
- [ ] Validate social previews after deploy and check responsive share controls.

## Human distribution
- [ ] Account owner approves each company/social/profile edit.
- [ ] Publisher/partner relationship and destination relevance verified.
- [ ] Customize description and UTM source/content; record placement evidence.
- [ ] Accept nofollow; reject bulk links, PBNs, fake profiles/reviews/locations and paid-follow schemes.
- [ ] Record live URL only after verification; schedule accuracy review/removal.

## Release
- [ ] `npm ci`, lint, typecheck, tests, build, both generators and `git diff --check` pass.
- [ ] Search Console/live URL checks are human follow-up; never promise indexing.
- [ ] Lead API, persistence, numbering, Gmail, UAE timestamps, deduplication, attribution, AI qualification, form, WhatsApp, sitemap and canonical behavior are unchanged or explicitly regression-tested.
